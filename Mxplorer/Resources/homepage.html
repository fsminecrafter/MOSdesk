Good to know

HTTPS sites

Turn on Unsafe HTTPS in Settings to open https:// pages. Certificates are not checked yet, so never type passwords or private data.

Developer tools

Press F12 for the console, the live element inspector, network requests, page source and timings.

Shortcuts

Ctrl+T new tab, Ctrl+W close, Ctrl+L address bar, Ctrl+R reload, Alt+Left back.

Mxplorer renders HTML, CSS and JavaScript. Images and video are not supported yet.
